# SyncCent - Simple Money Manager Demo

This is a simplified version of the SyncCent money management app built with Python and Flask.

## How to run:

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the app:**
   ```bash
   python app.py
   ```

3. **Open in browser:**
   Go to [http://127.0.0.1:5001](http://127.0.0.1:5001)

## Current Features:
- Add expenses with categories.
- View real-time list of expenses.
- Automatic total calculation.
- Local data persistence (JSON).
